    影策 · AI 漫剧创作工作台

    把剧本、角色、分镜与生成镜头放进同一个创作流程，让想法从文字走向可播放的样片。

    查看设计思路与成果

    开发方式与我的工作

    以开源影策 Open AI Canvas 为基础，使用 Codex 辅助二次开发。围绕自己的漫剧制作需求，梳理创作流程，完成本机 Codex 连接、画布来源连线与智能排版等定制，并在 Windows 本机运行。

    开发辅助
    Codex：代码实现、调试与验证
    前端界面
    React / TypeScript / Vite
    后端与数据
    Go / Gin / SQLite
    本机连接
    Node.js：连接 Codex 与创作画布
    视频处理
    FFmpeg：镜头转码与合并输出

    设计思路：让素材之间有明确关系

    从实际创作中“资料分散、角色参考难复用、生成结果难追溯”的问题出发，用画布承载剧本、角色、场景和镜头。参考素材与生成结果按真实来源连线，自动整理时沿来源向右展开，保留手动布局，减少反复找素材、整理节点的操作。

    希望达到的目的

    建立“剧本 → 角色与场景参考 → 分镜 → AI 镜头 → 合并预览”的制作路径。文本和图片可接入本机 Codex，视频沿用模型渠道，让创作者在同一工作区组织素材、比较结果并推进成片。

    已经呈现的结果

    开发方式与工具

    围绕个人影视创作需求设计的 Windows 桌面应用，将剧本整理、拍摄方案、AI 拆分镜和图文编辑集中到同一工作区。数据存储在本机，模型调用通过可配置的 API 接入，方便按自己的制作流程使用。

    设计思路：先确定拍法，再落成分镜

    直接按句子切分剧本，容易丢失叙事节奏和空间关系。因此把 AI 拆分镜分成两步：先梳理每场戏的叙事任务、节拍与空间调度，再逐场落实镜头。角色、场景和风格信息参与后续画面提示，减少人物外观与画面左右关系的反复变化。

    希望达到的目的

    让创作者从剧本出发，逐步完成拍摄方案、镜头顺序、景别、运镜、对白与时长的编排。分镜表支持自定义列、局部修改、图文编辑和自动保存，并通过制作前检查发现缺失信息，把前期构思整理为可继续制作的资料。

    已经呈现的结果

    已产出《加班贷》5 场、60 个镜头的图文分镜表，并提供导演简版、技术版 PDF 与分镜资料包。软件已形成 Windows 安装包，包含分镜编辑、角色与场景资产、制作包导出及本地备份恢复等模块。

    定位于前期策划、分镜设计与制作交接；实际视频生成交由后续创作台完成。
