# 崔瑞昊 · 个人作品集

[访问作品集](https://crh1381328-code.github.io/portfolio/)

个人作品集网站，展示游戏视频、商业合作、AIGC 视频、创作软件项目与 AE 动效，并提供经历、技能、联系方式及简历下载。

使用静态 HTML、CSS 和 JavaScript；基于 [vCard](https://github.com/codewithsadee/vcard-personal-portfolio) 定制，保留原 MIT 许可；图标来自 Lucide，许可见 assets/icons/。

## 本地预览与验证

```sh
node scripts/preview.mjs
```

访问 http://127.0.0.1:4173/ 。另开终端运行：

```sh
node scripts/verify.mjs
node scripts/verify-preview.mjs
```
